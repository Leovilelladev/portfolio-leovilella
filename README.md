# Portfolio — Leonardo Vilella

Prévia visual de um portfólio pessoal para Leonardo Vilella, desenvolvedor Front-end.

## O projeto

Uma landing page responsiva com identidade visual escura, destaque verde-limão e curadoria de projetos reais do GitHub.

Inclui:

- apresentação pessoal;
- projetos em destaque;
- filtros por tecnologia;
- seção de stack;
- tema claro/escuro;
- layout responsivo;
- links para os repositórios originais.

## Como visualizar

Abra o arquivo [index.html](./index.html) no navegador ou sirva a pasta com um servidor estático.

## Tecnologias

HTML, CSS e JavaScript puro.
